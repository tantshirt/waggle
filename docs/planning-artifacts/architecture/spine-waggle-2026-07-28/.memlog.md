- (constraint) Inherited binding from PRD/brief, not re-decided: distro not fork; three deliverables; gates = Buzz approval gates; TEA pilot; all 7 modules eventually; Apache-2.0; no dependency outside substrate/method/Nostr ecosystems.
- (direction) Paradigm: hexagonal (ports and adapters). Chosen because waggle sits between two systems it does not own -- hexagonal makes 'does not own' structural rather than aspirational, and confines each foreign contract to one adapter. Also mirrors the substrate's own zero-I/O-core layering, keeping a future upstream contribution idiomatic.
- (decision) OQ-8 resolved by owner: Rust. Rejected Python (would have made resolver reuse free) and TypeScript. Consequence: the BMAD override merge must be PORTED, so AD-5's differential test moves from optional to mandatory and non-skippable in CI. This is the single largest correctness risk the language choice introduced.
- (decision) OQ-6 resolved by owner: waggle CI builds the relay image from upstream's unmodified Dockerfile at the pinned tag and publishes it; operators pull. Driven by the finding that upstream publishes NO relay container image -- releases are desktop binaries only. Confines the Rust 1.88+ substrate build requirement to CI, so operators need only a container runtime. Cost accepted: waggle takes on image-publishing and supply-chain responsibility.
- (decision) OQ-4 resolved by owner: standard kinds first, custom kinds claimed only for genuine gaps and each requiring written rationale in a committed registry. Preserves the portability differentiator (NFR-6) and matches the substrate's own stated philosophy.
- (decision) OQ-2 resolved: size-based transport against the substrate's real frame limit, not always-reference. Rationale -- putting a small gate verdict behind a blob reference would make it unreadable to a third-party NIP client, defeating the portability claim precisely where it matters most. Verdicts and handoffs stay inline.
- (decision) OQ-5 resolved: gate authorization reads the relay-signed admin list (kind 39001) rather than a waggle-maintained approver roster, which would drift from actual workspace membership. WAIVED requires owner; PASS/CONCERNS/FAIL require admin or owner.
- (decision) OQ-7 resolved: body materialization is discovered via the installation manifest's own tool list, never a hard-coded path. Forced by the finding that skill-manifest.csv path values point at files that do not exist on disk.
- (decision) OQ-1 forced by the Rust choice: port the merge AND run a differential test against the method's own resolve_customization.py over every installed agent. Not a free choice any more -- it is the only defense against silently-wrong personas.
- (decision) Gate state authority is the event log, not substrate workflow run status (AD-10). This is not a workaround for UP-01 -- FR-22 already required log-only reconstruction, so LogReconciledGate IS that requirement's implementation. If upstream never fixes UP-01, waggle is still correct.
- (decision) AD-11 tripwire: a test asserts the pinned substrate's CURRENT broken approval behavior, so an upstream fix breaks the build and forces a deliberate re-pin. Prevents the degraded adapter quietly outliving its justification.
- (decision) AD-16 forbids any module-specific conditional in waggle-core or waggle-emit. This is SM-C1 made structural: it is the mechanism that stops the compiler degenerating into hand-written config with a build step.
- (decision) AD-14 confines secret key material to the identity adapter behind the port, in a type with no Debug/Display. Chosen because nsec leakage is the one failure mode with no remediation.
